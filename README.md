# Biblioteca Digital UniFECAF

Site estático (HTML e CSS) da disciplina Design Web.

## Estrutura

```
biblioteca-digital/
├── index.html
├── css/style.css
├── assets/imagens/
```

Para ver localmente, abra o `index.html` no navegador.

## Publicar no Railway

1. Envie esta pasta para um repositório público no GitHub.
2. No Railway: **New Project > Deploy from GitHub repo** e escolha o repositório.
3. Escolha o repositório e aguarde o deploy terminar.
4. Em **Settings > Networking**, clique em **Generate Domain** para obter o link público.
